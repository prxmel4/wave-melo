# wavemelo v0.11.0

## Highlights

- Six audio-filter presets backed by Lavalink's native filter model.
- Autocomplete for preset names.

## Added

- `/filter <preset>` supports `bassboost`, `nightcore`, `vaporwave`, `8d`,
  `karaoke`, and `clear`.
- `src/audio/filters.rs` builds complete `Filters` values from verified
  lavalink-rs structures; each update replaces the previous filter set.
- Autocomplete suggests matching presets case-insensitively.

## Changed

- Active filter state persists in per-guild session state and is shown by
  `/nowplaying`.

## Security and integrity

- Preset resolution uses a fixed allow-list; no raw filter JSON is accepted
  from users.
- Same-voice-channel authorization is required before applying a filter.

## Upgrade instructions

Restart the bot to register `/filter`. No configuration changes required.

## Known limitations

- Filter presets are fixed; custom equalizer bands are not exposed.
- Live audio output remains unverified without a running deployment.
