# wavemelo v0.4.0

## Highlights

- Added validated core playback controls: `/volume`, `/pause`, and `/resume`.
- Introduced a shared playback operations module so slash commands and future
  interactive controls use identical behavior.

## Added

- `/volume <0..150>` with strict boundary validation (100 is the default
  playback level; 0 mutes).
- `/pause` and `/resume` with same-voice-channel authorization and active-player
  checks.
- Idempotent handling of already-paused and already-playing states.
- Structured INFO logs for volume changes and pause transitions.
- Unit tests for full-range volume acceptance, out-of-range rejection, and
  strict text parsing.

## Changed

- Playback business logic now lives in `src/playback/ops.rs`, separate from
  Discord reply rendering.

## Upgrade instructions

Register the new slash commands by restarting the bot. Poise registration runs
at startup; no Lavalink configuration changes are required.

## Known limitations

- Same-channel authorization requires the bot to be connected already; use
  `/play` or `/join` first.
- Live Discord interaction and audio output remain unverified without a
  running Discord/Lavalink deployment.
