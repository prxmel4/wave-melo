# wavemelo v0.7.0

## Highlights

- Added full queue management: remove, jump, move, and clear.
- All indices are validated as 1-based positions before any queue mutation,
  avoiding the internal panic path in lavalink-rs for out-of-range inserts.

## Added

- `/queueremove <index>` removes one queued track.
- `/queuejump <index>` extracts a queued track, places it at the front, and
  skips to it immediately.
- `/queuemove <from> <to>` reorders the queue without losing entries.
- `/queueclear` empties the queue while the current track keeps playing.
- `src/queue/ops.rs`: pure, unit-tested index validation, reorder, and jump
  planning shared by all four commands.
- Same-voice-channel authorization on every queue management command.

## Changed

- `/queueclear` clears the queue-loop snapshot so repeat cycles cannot
  resurrect removed tracks.

## Upgrade instructions

Restart the bot to register the four new slash commands. No configuration or
Lavalink changes are required.

## Known limitations

- Queue positions refer to upcoming tracks only; the current track is managed
  with `/skip`, `/stop`, and `/seek`.
- Live Discord interactions and audio output remain unverified without a
  running deployment.
