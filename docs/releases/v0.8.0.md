# wavemelo v0.8.0

## Highlights

- Added slash-command autocomplete for `/loop` and `/play`.
- Track starts populate bounded local history used by `/play` suggestions.

## Added

- `src/autocomplete.rs` with Unicode-safe choice clipping, case-insensitive
  filtering, and a five-suggestion cap.
- `/loop` autocomplete for `off`, `track`, and `queue`.
- `/play` autocomplete from the guild's bounded recent-title history.
- Tests for filtering, clipping, and static mode suggestions.

## Changed

- `on_track_start` records the title in per-guild history and increments the
  idle generation counter.

Restart the bot so Discord receives the updated command definitions with
autocomplete enabled.

## Known limitations

- `/play` suggestions come from in-process history only and are empty until
  tracks have been played in the current process.
