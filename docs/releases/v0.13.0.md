# wavemelo v0.13.0

## Highlights

- `/autoplay` keeps the music going by resolving related tracks when a track
  finishes naturally with an empty queue and no loop mode active.
- YouTube Mix playlists are the primary source, with a `ytsearch:` fallback;
  recently played identifiers are never repeated.
- Autoplay resolution runs in a cancellable background task so manual commands
  always take precedence and no failure loop can run indefinitely.

## Added

- `/autoplay` slash command (same-voice authorization) toggles per-guild
  autoplay. Enabling resets the failure budget; disabling cancels any pending
  task.
- `src/audio/autoplay.rs` with pure, deterministic helpers: `video_id`,
  `mix_url`, `search_fallback`, `should_autoplay`, `pick_candidate`, `dedupe`,
  and `loaded_candidates`, plus a cancellable `AutoplayControl` task slot.
- `recent_identifiers` in guild state: a bounded, deduplicated history of track
  identifiers recorded on every `on_track_start`, used to skip the Mix seed
  video and recently played songs.
- `autoplay_failures` counter: after three consecutive resolution failures
  autoplay pauses itself until re-enabled.

## Changed

- `on_track_end` spawns related-track resolution only for `Finished` ends with
  an empty queue and loop mode `Off`; all resolution happens after the event
  handler yields, so no network I/O blocks Lavalink's dispatcher.
- The final `play_now` acquires the shared per-guild operation lock and
  re-verifies autoplay state, generation, loop mode, queue, and dedup history,
  so user actions during resolution always win.
- `/play`, `/skip`, `/stop`, forced voice disconnects, and
  `GuildStateRegistry::remove` cancel any pending autoplay task.
- `/247` remains authoritative: idle disconnect cleanup cancels autoplay too.

## Security and integrity

- `video_id` accepts only known YouTube hosts and validates the 11-character
  ID character set, preventing query injection into the Mix URL.
- Bounded histories (20 entries) and a bounded failure budget prevent
  unbounded memory growth and infinite retry loops.
- Every play decision re-checks the generation token and playback state under
  the guild operation lock.

## Upgrade instructions

Restart the bot to register `/autoplay`. No configuration or Lavalink changes
are required. Autoplay is off by default per guild; enable it with `/autoplay`
while in the same voice channel as the bot.

## Known limitations

- Mix results depend on YouTube's related-video recommendations; when none are
  playable, the title/artist search fallback is used instead.
- Autoplay is per guild, not per user; any member in the same voice channel can
  toggle it.
