# wavemelo v0.12.0

## Highlights

- Smart 180-second auto-leave when the bot is alone in a voice channel or idle
  with an empty queue.
- `/247` slash command to suppress auto-leave and keep the bot connected 24/7.
- Cancellable Tokio timer with per-guild generation counters so stale timers
  can never disconnect an active session.

## Added

- `/247` slash command (Poise `rename = "247"`) toggles per-guild 24/7 mode.
  Requires same-voice-channel authorization.
- `src/audio/idle.rs` with a pure decision function (`leave_required`), a
  cached listener counter, and the cancellable `IdleControl` primitive.
- Runtime-handle registration in the `GuildStateRegistry` so Lavalink event
  handlers and background timers can reach the shard messenger and cache
  without a per-event Serenity `Context`.
- `Registry::remove` now cancels any armed countdown before dropping the
  session.

## Changed

- `on_track_end` re-evaluates the idle countdown for every end reason
  (including manual `/stop`), while loop replenishment remains scoped to
  natural `Finished` ends.
- `on_track_start` and voice-state updates refresh the countdown so new tracks
  or returning listeners cancel it immediately.
- `send_voice_state_update` now takes the shard messenger directly, allowing
  background tasks to disconnect without a per-event `Context`.
- The `Ready` handler installs runtime handles so every downstream handler can
  reach the cache and shard.

## Security and integrity

- Every idle disconnect re-verifies 24/7 mode, listener count, playback
  state, and queue length under the per-guild operation lock before acting.
- Generation counters prevent cancelled or superseded timers from firing
  against a rebuilt session.
- Same-voice-channel authorization is required to toggle `/247`.

## Upgrade instructions

Restart the bot to register `/247`. No configuration or Lavalink changes are
required. Auto-leave activates automatically whenever the bot is alone or idle.

## Known limitations

- The countdown is fixed at 180 seconds; it is not configurable through
  slash commands or environment variables.
- Auto-leave is reactive to voice-state updates; a gateway outage that
  prevents those updates will also prevent the countdown from advancing.
