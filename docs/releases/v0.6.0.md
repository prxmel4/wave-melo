# wavemelo v0.6.0

## Highlights

- Added per-guild session state that is shared safely with Lavalink event
  handlers.
- Added `/loop` with `off`, `track`, and `queue` modes backed by buffered
  internal repeat copies.

## Added

- `GuildStateRegistry` with synchronous atomic loop-mode reads and bounded
  snapshots. Standard mutexes are held only for short in-memory operations and
  never across `.await` or network I/O.
- `/loop <off|track|queue>` with same-voice authorization and active-player
  checks. Two buffered copies prevent the short race between Lavalink's
  automatic advance and event-side replenishment.
- Internal loop markers are removed from the queue when modes change, so user
  tracks remain authoritative.
- `/nowplaying` now shows the stored loop mode and active filter.
- Tests for loop transitions, marker tagging/stripping, snapshot bounds, and
  registry reuse.

## Changed

- Lavalink is initialized with shared user data so event handlers can access
  per-guild session controls without Discord API calls.
