# wavemelo v0.3.0

## Highlights

- Completed the English-only localization milestone: every bot-controlled
  string in `src/` is now professional English. External track titles, artist
  names, playlist names, and user queries keep their original language.
- Fixed a Unicode truncation defect where very small limits returned a string
  longer than the requested maximum.

## Added

- Deterministic regression test that scans `src/**/*.rs` for Thai Unicode
  characters (U+0E00–U+0E7F).
- Tests for truncation at small limits and across Unicode character boundaries.

## Changed

- Command responses, embeds, error messages, framework errors, and their tests
  now use consistent English terminology.
- `README.md` documents the English-only reply policy and Unicode input support.
- `truncate()` never exceeds the requested character limit.

## Removed

- All Thai-language literals from `src/` and their obsolete test expectations.

## Upgrade instructions

No configuration changes are required. Pull the new release and restart the bot;
`docker compose up --build -d` rebuilds the image from the tagged source.

## Known limitations

- Live Discord gateway, voice handshake, and YouTube playback require a running
  bot and Lavalink node and were not exercised in this release's automated tests.
- This release contains no new slash commands beyond the existing v0.2.0 set.
