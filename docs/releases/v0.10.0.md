# wavemelo v0.10.0

## Highlights

- Queue randomization and playback history.
- Interactive queue pagination with strict `wavemelo:queue:*` component IDs.

## Added

- `/shuffleq` randomizes queued tracks with a time-seeded xorshift64 PRNG.
- `/history` shows the 20 most recent track titles from bounded state.
- `/queue` now includes First/Previous/Next/Last buttons; page IDs carry the
  guild and page number and are validated for canonical decimal fields.
- `src/queue/pagination.rs` with pure, tested page arithmetic.

## Changed

- Shuffle is rejected while loop mode is active so marker-based replenishment
  cannot be corrupted.

## Security and integrity

- Queue-page interactions are bound to the originating guild; foreign IDs and
  malformed numbers are rejected with a private error.
- Queue pages are read-only and require no voice-channel gate.

## Upgrade instructions

Restart the bot to register `/shuffleq` and `/history`. No configuration
changes are required.

## Known limitations

- History is in-process and resets on restart.
- Queue pagination buttons are refreshed from live Lavalink state on every
  click; pages may shift if the queue changes concurrently.
